# Collection and source/output terms

This prepared package does not assert a new license grant for the authored text,
teacher responses or collection. Before public publication, the publisher must
choose and document that grant here and in the dataset card.

Source model licenses do not automatically choose a dataset license. Text authoring
and teacher inference used Qwen models; older synthesis used Qwen CustomVoice.
Their model cards list Apache 2.0. No source model weights are redistributed.

The Neu collection additionally contains audio generated by NeuTTS-2E. Its
**NeuTTS Open License 1.0, section 5(a), expressly includes Outputs** in its
commercial-use condition, with a US$5 million annual-revenue threshold. The
unchanged pinned upstream license accompanies that collection. These conditions
must not be removed or contradicted by the publisher's additional grant.

The Qwen collection contains no Neu audio; Neu's output condition therefore does
not apply to that collection. Neither package contains DeepDialogue-derived
ordinary examples. Those have separate CC BY-NC 4 source terms.
